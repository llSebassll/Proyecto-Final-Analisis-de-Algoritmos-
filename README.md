# Proyecto-Final-An-lisis-de-Algoritmos-
# Rutas del Paisaje Cultural Cafetero

Proyecto académico para la asignatura de Algoritmos. Este sistema modela la red vial del Quindío utilizando grafos reales y evalúa el rendimiento de algoritmos de optimización de rutas (Dijkstra, Envolvente Convexa y Problema del Viajante) bajo restricciones de tiempo.

#Requisitos Previos
- Python 3.9 o superior instalado en tu sistema.
- Conexión a internet (para renderizar los mapas base de OpenStreetMap).

#Instalación y Configuración Local

Sigue estos pasos para ejecutar el proyecto en tu máquina local:

1. **Clonar o descomprimir el proyecto:**
   Abre una terminal y navega hasta la carpeta raíz del proyecto (donde se encuentra `main.py`).

2. **Crear un entorno virtual**
   ```bash
   python -m venv .venv

3. **Activar el entorno virtual**
   .venv\Scripts\activate

4. **Activar el entorno virtual:**
   pip install -r requirements.txt

5. **Pruebas y Resultados de Consola**
   python main.py

6. **Aplicación Web Interactiva**
   streamlit run app.py
